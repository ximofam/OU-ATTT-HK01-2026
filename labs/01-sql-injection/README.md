# LAB-01 — SQL Injection

**Challenge:** Login Admin (OWASP Juice Shop)  
**Công cụ chính:** Burp Suite Community, trình duyệt.

## Cần thực hiện

- [ ] Nghiên cứu cơ chế SQL Injection và lỗi xử lý đầu vào.
- [ ] Khởi động Juice Shop local.
- [ ] Quan sát chức năng đăng nhập hợp lệ và HTTP traffic.
- [ ] Tái hiện challenge Login Admin trong Lab.
- [ ] Lưu ảnh và request/response đã làm sạch tại `evidence/`.
- [ ] Giải thích nguyên nhân, tác động và cách sử dụng parameterized queries.
- [ ] Viết tài liệu theo `docs/LAB_TEMPLATE.md`.

## Đầu ra

Một báo cáo độc lập, bằng chứng thực nghiệm và kịch bản demo có thể lặp lại. Không đưa mật khẩu thật, session token hoặc dữ liệu cá nhân vào repo.
