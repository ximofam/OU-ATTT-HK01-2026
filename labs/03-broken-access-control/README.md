# LAB-03 — Broken Access Control

**Challenge:** View Basket (OWASP Juice Shop)  
**Công cụ chính:** Burp Suite Community, trình duyệt.

## Cần thực hiện

- [ ] Nghiên cứu authorization, ownership và IDOR/horizontal privilege escalation.
- [ ] Khởi động Juice Shop local.
- [ ] Tạo hai tài khoản thử nghiệm A/B có giỏ hàng phân biệt.
- [ ] Quan sát request của chức năng giỏ hàng cho từng tài khoản.
- [ ] Tái hiện challenge View Basket trong Lab.
- [ ] Lưu ảnh/request/response đã ẩn token tại `evidence/`.
- [ ] Giải thích vì sao cần kiểm tra quyền truy cập ở phía server.
- [ ] Viết tài liệu theo `docs/LAB_TEMPLATE.md`.

## Đầu ra

Một báo cáo độc lập, bằng chứng thực nghiệm và kịch bản demo có thể lặp lại. Chỉ dùng tài khoản giả lập của nhóm.
