# LAB-02 — DOM XSS

**Challenge:** DOM XSS (OWASP Juice Shop)  
**Công cụ chính:** Browser DevTools; Burp Suite nếu cần kiểm tra traffic.

## Cần thực hiện

- [ ] Nghiên cứu XSS và phân biệt DOM XSS với Reflected/Stored XSS.
- [ ] Khởi động Juice Shop local.
- [ ] Khảo sát cách dữ liệu của người dùng được xử lý trong DOM.
- [ ] Tái hiện challenge DOM XSS trong Lab.
- [ ] Lưu ảnh chụp hành vi và phân tích source/sink tại `evidence/`.
- [ ] Giải thích root cause và các giải pháp như safe DOM APIs/encoding đúng ngữ cảnh.
- [ ] Viết tài liệu theo `docs/LAB_TEMPLATE.md`.

## Đầu ra

Một báo cáo độc lập, bằng chứng thực nghiệm và kịch bản demo có thể lặp lại. Không thu thập hoặc gửi dữ liệu thật của người dùng.
